# 📱 Social Media Clone (Responsive)

A fully responsive **Social Media Clone UI** built using **HTML and CSS**.
This project was created during the **Tech Leap Session**, where the goal was to design a social media interface layout similar to modern platforms.

The layout is built using **CSS Grid and Flexbox** to create a clean and responsive design that adapts to different screen sizes.

---

## 🚀 Features

* Fully **Responsive Design**
* Built with **CSS Grid & Flexbox**
* Social media style **navigation icons**
* Responsive **image grid gallery**
* Clean **UI layout similar to modern social platforms**
* Mobile-friendly layout

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Font Awesome Icons
